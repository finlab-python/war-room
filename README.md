# FinLab 戰情室（實驗版）

輸入一個事件，沿著供應鏈推出會受影響的台股公司，再拿真實股價與月營收檢查推論對不對。

- 公開版：https://war-room-748308483506.asia-east1.run.app
- 桌機版（用你自己的 Claude Code 或 Codex 推論任何事件）：

  ```bash
  uvx --from git+https://github.com/finlab-python/war-room war-room
  ```

  需要先裝好並登入 [Claude Code](https://claude.ai/install.sh) 或 Codex CLI。資料向公開版拿，AI 跑在你的電腦和你的訂閱上，跟 FinLab Desktop 一樣。

## 怎麼推論

一張圖，四層：

| 層 | 內容 | 來源 |
|---|---|---|
| 世界層 | 事件、咽喉點、原物料，以及原物料之間怎麼傳（原油 → 輕油 → 乙烯 → PE） | 人工整理，每條邊附理由與出處（`pipeline/world.py`） |
| 產業鏈 | 1,993 家公司分屬約 500 個產業鏈環節 | 櫃買中心產業價值鏈（FinLab `security_industry_themes`） |
| 年報 | 每家公司的主要原料、產品、供應商、客戶，以及公司自己說的風險 | AI 讀股東會年報抽出，每條附頁碼與引文 |
| 驗證 | 事件後一週、一個月、三個月的超額報酬與月營收年增率 | FinLab 股價與營收，存在 ClickHouse |

從事件出發沿邊往外走，每條邊有權重（影響多直接）與方向（受惠、受害、未定）。一家公司常被好幾條路碰到（原料漲價受害、產品漲價受惠），所有有方向的路加總看淨影響。

驗證只用事前就知道的關係（產業鏈、原料、產品、供應商），不用公司事後在年報裡的自述，避免拿答案當題目。

## 資料怎麼壓

- 年報 PDF 只在記憶體裡轉成文字，全文逐頁存進 ClickHouse（ZSTD 壓縮），大約是 PDF 的 1/50；證據面板直接從這裡調出原文那一頁。
- AI 只讀營運概況（原料、產品、進銷貨）和提到中東、油價、運價的幾頁，一份兩百頁的年報壓成幾十條關係。
- AI 給的引文要逐字出現在那一頁，對不上就丟掉，這是擋「抽錯東西」的第一道關。
- 整張圖（約 2,500 個節點、6,500 條邊）壓縮後 85 KB，一次載入，推論在瀏覽器裡算，不到 1 毫秒；股價與營收由 ClickHouse 即時算，兩百多家約 60 毫秒。

## 資料管線

在 Mac Studio 跑（要 FinLab 登入）：

```bash
uv sync --extra pipeline
uv run python pipeline/fetch.py     # 下載年報，抓過的跳過
uv run python pipeline/extract.py   # AI 抽關係（用這台的 Claude Code），抽過的跳過
uv run python pipeline/build.py     # 全部寫進 ClickHouse，幾秒
uv run war-room                     # 本機網站
./deploy.sh                         # 更新公開版
```

三步都是增量的：每天重跑，只處理新的年報。

## 驗證結果（2026-11-05，前 84 家年報）

推論受惠組減推論受害組的平均超額報酬（相對全體上市櫃等權平均），單位是百分點：

| 事件 | 一週 | 一個月 | 三個月 |
|---|---|---|---|
| 2026 美伊戰爭 | +3.8 | +1.9 | −15.4 |
| 2025 以伊 12 日戰爭 | +0.8 | −1.2 | +1.8 |
| 2023 紅海危機 | +2.4 | +0.8 | +1.8 |
| 2022 俄烏戰爭 | +1.8 | +1.3 | +3.4 |

一週內四次都對，之後就被別的因素蓋過；2026 這次三個月後反轉。

## 還沒做好的

- 世界層的方向是人工依產業常識設定的。下一步是用過去的事件自動校正每條邊的方向與權重，再拿新事件驗證。
- 年報先收錄能源、原物料、運輸相關的 280 家，其餘之後補。
- 同一件事在新聞、法說會的說法還沒進來。
